# T01 — Repository bootstrap

Read first: `AGENTS.md`, `docs/DECISIONS.md` (D-001..D-006, D-010, D-011).

## Goal
A clean, building, tested skeleton that every later task extends. Production quality from line one.

## Deliverables
1. **Submodules** under `ThirdParty/<name>` pinned to these refs (add with `git submodule add`, then checkout
   the tag; record the exact tag/commit in `ThirdParty/README.md` with license per dependency):
   glfw `3.4`, NVRHI (`main` HEAD, recursive — it carries Vulkan-Headers), glm `1.0.3`, imgui (`docking` branch HEAD
   commit), ImGuizmo (master HEAD), entt `v3.16.0`, JoltPhysics `v5.6.0`, lua (`v5.4.8` from github.com/lua/lua),
   sol2 `v3.5.0`, miniaudio `0.11.25`, stb (master HEAD), cgltf `v1.15`, nlohmann json `v3.12.0`, doctest `v2.5.3`,
   glslang (`vulkan-sdk-1.4.363.0`), nanosvg (master HEAD), earcut.hpp `v3.2.4`, cpp-httplib `v0.60.1`,
   Monocypher `4.0.3`, lz4 `v1.10.0`, xxHash (`v0.8.3`, Cyan4973/xxHash).
   Use shallow submodules where possible (`git config -f .gitmodules submodule.<x>.shallow true`).
   Do not run NVRHI's or glslang's own heavy builds yet — later tasks wire them.
2. **CMake**: top-level `CMakeLists.txt` (C++20, options `GB_BUILD_EDITOR`, `GB_BUILD_RUNTIME`, `GB_BUILD_CLI`,
   `GB_BUILD_TESTS`, `GB_WARNINGS_AS_ERRORS`; custom `Dist` config defining `GB_DIST`, output to
   `build/<Config>/bin`), `cmake/` helpers (`GambitCompilerOptions.cmake`: warning flags + determinism float flags
   from D-011 applied to engine targets only; ccache auto-detect), `ThirdParty/CMakeLists.txt` defining
   interface/static targets for the deps needed now: glm, doctest, nlohmann_json, EnTT, glfw, xxhash, lz4,
   monocypher, stb (one `stb_impl.cpp` in engine later — header target now). Third-party targets build with
   warnings disabled. `CMakePresets.json` with configure/build/test presets for linux/windows/macos ×
   Debug/Release/Dist (Ninja).
3. **Engine library `Gambit`** (static): `Gambit/src/gbpch.h` (PCH), `Gambit/src/Gambit.h` (umbrella),
   `Gambit/Core/{Base.h, PlatformDetection.h, Log.h/.cpp, Assert.h, Result.h}`:
   - `Base.h`: `Ref/Scope/CreateRef/CreateScope`, `GB_BIT`, `GB_EXPAND_MACRO`, `GB_STRINGIFY_MACRO`, debugbreak.
   - `Log`: `std::format`-based logger with core/client loggers, levels, pluggable sinks (console with colors,
     file, in-memory ring buffer with capacity + thread-safe snapshot), `GB_CORE_TRACE/INFO/WARN/ERROR/CRITICAL`
     and client `GB_*` macros. Thread-safe.
   - `Assert.h`: `GB_CORE_ASSERT/GB_ASSERT` (compiled out in Dist), `GB_CORE_VERIFY/GB_VERIFY` (always on).
   - `Result<T>`: value-or-error (error = string message + optional code), `[[nodiscard]]`.
4. **Executables** (minimal but real, compile and run): `GambitCLI` producing binary `gambit` supporting
   `gambit --version` and `gambit --help` with a small sub-command dispatcher designed to grow (later tasks add
   commands); `GambitRuntime` and `GambitEditor` mains that just log version and exit 0 for now.
   Version in one place (`Gambit/src/Gambit/Core/Version.h`, `0.1.0`).
5. **Tests**: `GambitTests` (doctest, registered with CTest; custom `main` that initializes Log). Tests for Log
   (ring buffer sink captures, level filtering, format), Result, Assert-free paths.
6. **Scripts** (Python 3, cross-platform, quiet per D-006): `scripts/build.py`, `scripts/test.py`
   (`--no-gpu` sets `GB_TEST_NO_GPU=1`, `--filter`), `scripts/format.py` (`--check`; runs clang-format over
   engine/editor/runtime/cli/tests sources, never ThirdParty), `scripts/check.py` (format check + build +
   tests). Output: errors + one summary line; full logs in `build/logs/`.
7. **Repo hygiene**: `.clang-format` encoding AGENTS.md §2 (tabs, Allman, `PointerAlignment: Left`,
   `NamespaceIndentation: All`, ColumnLimit 120, include sorting off or grouped per §2), `.editorconfig`,
   `.gitignore` (build/, .cache/, *.user, compile_commands.json symlink, etc.), `.gitattributes` (LF; binary for
   png/hdr/glb/wav/ogg/ttf), `README.md` (what Gambit is, build quickstart, links to docs).
8. **CI**: `.github/workflows/ci.yml` — Linux (GCC + Clang; install X11/Wayland dev pkgs + `mesa-vulkan-drivers`,
   run all tests incl. GPU under lavapipe), Windows (MSVC), macOS (AppleClang; `--no-gpu`). Checkout with
   submodules recursive; cache ccache. Runs `scripts/check.py` equivalent.
9. **Skills**: `.claude/skills/build-and-test/SKILL.md` (how to build/test/debug failures quietly) and
   `.claude/skills/code-review/SKILL.md` (review checklist: style table, error handling, determinism rules,
   strict ECS, reflection registration, tests present, no dead code, docs updated, commit hygiene). Skills use
   the standard frontmatter (`name`, `description`).

  GCC and Clang (`CC=clang CXX=clang++`), zero warnings.
- `build/Debug/bin/gambit --version` prints the version.
