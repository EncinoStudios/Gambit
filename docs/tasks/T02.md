# T02 — Core services & deterministic math

Read first: `AGENTS.md`, D-010, D-011, D-013, D-014 in `docs/DECISIONS.md`. Builds on T01.

## Deliverables (engine library, with doctest tests for everything)
1. `Core/UUID.h/.cpp` — 64-bit UUID. `UUID::Generate()` (non-deterministic, authoring only; thread-safe
   `std::mt19937_64` seeded from `std::random_device`), `UUID(uint64_t)`, `ToString()` → `"0x%016llX"`,
   `UUID::Parse(std::string_view)` → `std::optional<UUID>`, comparison, `std::hash`. 0 = invalid.
2. `Core/Buffer.h` — owning `Buffer` (move-only, `Allocate/Release/Copy`, `As<T>()`), `BufferView`.
3. `Core/FileSystem.h/.cpp` — `ReadBinary/ReadText` → `Result<...>`, `WriteBinary/WriteText` (atomic: write temp
   then rename), `Exists`, `CreateDirectories`, `ListDirectory(path, recursive)`, `NormalizePath` (forward
   slashes, resolve `.`/`..`, reject escaping the root), `GetExecutableDirectory`.
4. `Core/VFS.h/.cpp` — `IFileMount` interface (`Exists`, `Read`, `List`, `IsWritable`, `Write`, `Remove`,
   `GetMountType`), `DirectoryMount` (read/write, confined to its root — reject `..` escapes and absolute
   paths), `VFS` with ordered mounts (later mounts shadow earlier for reads; writes go to the highest writable
   mount containing the mount point), virtual paths are relative with forward slashes, case-sensitive.
   `VFS::ReadText/ReadBinary/Write/Exists/List`. Thread-safe for concurrent reads. Pack/remote mounts come in
   T23/T24 — design the interface so they slot in.
5. `Core/Timer.h` (`Timer`, `ScopedTimer` logging to core logger) and `Core/TimeStep.h`
   (`TimeStep` wrapping seconds as float + tick index; `GetSeconds()`, `GetMilliseconds()`).
6. `Core/Hash.h` — `Hash::XXH64(data, size, seed)`, incremental `Hasher` (XXH3-64 or XXH64 streaming via xxHash),
   `HashCombine`, constexpr FNV-1a `Hash::FNV1a(std::string_view)` and `operator""_hash`.
7. `Math/Math.h` — single include for glm with project-wide config (`GLM_FORCE_DEPTH_ZERO_TO_ONE`,
   `GLM_FORCE_RADIANS`, `GLM_ENABLE_EXPERIMENTAL`; do NOT force SIMD intrinsics — determinism), set via CMake
   compile definitions on the Gambit target (PUBLIC) so every consumer agrees; helpers `DecomposeTransform`,
   `ComposeTransform`, `NearlyEqual`.
8. `Math/DMath.h/.cpp` — deterministic math for simulation code (D-011): `Sin, Cos, Tan, Asin, Acos, Atan,
   Atan2, Exp, Log, Log2, Pow, Fmod` for `double` and `float` (float versions may compute in double and round),
   implemented as ports of musl libm (MIT; keep the musl copyright notice in the file header) or equivalent
   pure IEEE-754 arithmetic — no calls into the platform libm except `sqrt`/`floor`/`ceil`/`trunc`/`fabs`
   (exactly rounded by IEEE). Plus `DMath::Quat/Vec` helpers needed by simulation: `AngleAxis`,
   `QuatFromEuler`, `Slerp`, `Normalize` using only DMath. Tests: accuracy vs std within 1-2 ulp on a dense
   sample set, and a checked-in table of bit-exact outputs (hex) for ~50 inputs per function so any
   platform/compiler drift fails CI.
9. `Math/Random.h/.cpp` — PCG32 (`pcg32_random_r` semantics: 64-bit state + stream), seeding
   `Random(uint64_t seed, uint64_t stream = 0)`, `NextU32`, `NextU64`, `NextFloat01` ([0,1), 24-bit), `NextDouble01`
   (53-bit), unbiased `RangeInt(min, max)` inclusive (Lemire or rejection), `RangeFloat(min,max)`, `NextBool(p)`,
   `NextGaussian` (Box–Muller with DMath), `InsideUnitSphere`, `OnUnitSphere`, `Shuffle(span)`,
   `GetState/SetState` (for save/hash/rollback). Tests: reference PCG32 outputs for known seeds (from the PCG
   reference implementation), range bounds, statistical sanity (chi-square on buckets), state round-trip.
10. Update `Gambit.h` umbrella and `gbpch.h` sensibly (PCH: std headers + glm, not engine headers that change often).
