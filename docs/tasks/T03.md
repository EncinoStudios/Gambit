# T03 — Application loop, window, input, replay

Read first: `AGENTS.md`, D-011, D-012, D-024 in `docs/DECISIONS.md`. Builds on T01–T02.

## Deliverables (with doctest tests)
1. **Events** (`Core/Events/`): Hazel-style `Event` base with type/category, `EventDispatcher`; window
   (close, resize, focus, framebuffer resize, content scale, file drop), key (pressed/repeat, released, typed),
   mouse (moved, scrolled, button pressed/released), gamepad connect/disconnect.
2. **Window** (`Platform/Window.h` interface + `Platform/GLFW/GLFWWindow.cpp`): `WindowSpecification`
   (title, width, height, vsync, resizable, fullscreen, decorated, maximized), creates GLFW window with
   `GLFW_NO_API` (Vulkan comes in T07), event callbacks → `Event`s, framebuffer size, content scale,
   cursor mode (normal/hidden/locked), `GetNativeHandle()`, clipboard, title. GLFW init/terminate ref-counted,
   errors routed to the core logger. Never `exit()` on failure — return `Result`.
3. **Application** (`Core/Application.h/.cpp`): `ApplicationSpecification` (name, working directory, args,
   `Headless` flag (no window), window spec, `SimulationHz` default 60, `MaxSimStepsPerFrame` default 8),
   Hazel-style `Layer`/`LayerStack` (`OnAttach/OnDetach/OnUpdate(TimeStep)/OnFixedUpdate(TimeStep)/
   OnRender(float interpolationAlpha)/OnEvent/OnImGuiRender` — ImGui hookup comes later), `Run()`, `Close()`,
   singleton `Application::Get()`. Main loop: poll events → frame time → `FixedTimestepClock` accumulator
   produces N fixed ticks (clamped; the clamp is logged once per occurrence burst) → for each tick sample an
   `InputFrame` and call `OnFixedUpdate` → `OnUpdate` → `OnRender(alpha)`. `RunFrames(n)` / manual stepping API
   for headless tests and tools (`Application::StepFixed(InputFrame)`), no window needed in headless mode.
4. **Input** (`Input/`):
   - `InputDevices`: polls GLFW keyboard/mouse/gamepad state (GLFW gamepad mappings) — non-deterministic source.
   - `InputFrame` (D-012): plain data — key bitset (all GLFW key codes mapped to a compact `KeyCode` enum),
     mouse button bits, mouse position + delta quantized to 1/64 px (int32), scroll quantized, up to 4 gamepads
     (buttons bitset + 6 axes as int16), text input codepoints (bounded array). `Sample()` from devices;
     equality, binary (de)serialization with versioned header.
   - `InputActions` (`InputActions.json` in projects): actions of type `Button` | `Axis1D` | `Axis2D` with
     bindings (key, mouse button, mouse delta axis, scroll, gamepad button, gamepad axis with deadzone/scale/
     invert, composite 2D WASD-style). `InputState` evaluated from current + previous `InputFrame`:
     `IsDown/WasPressed/WasReleased(action)`, `GetAxis(action)`, `GetAxis2D(action)` using only deterministic
     arithmetic (quantized inputs → float math, no libm).
   - `InputLog`: header (version, project name, scene path, seed, sim Hz) + frames; record, save/load binary
     (`.ginput`) with validation, iterate for replay. `InputSource` interface: `DeviceInputSource` (live) vs
     `ReplayInputSource` (log); Application uses the configured source.
5. **Entry point**: `Core/EntryPoint.h` Hazel-style `CreateApplication(ApplicationCommandLineArgs)`; update
   `GambitRuntime` and `GambitEditor` to open a window (or headless with `--headless --frames N`) and exit cleanly.
6. **Tests**: event dispatch, fixed-timestep accumulator (exact tick counts for synthetic frame times, clamping),
   InputFrame serialization round-trip, InputActions JSON parsing errors + evaluation (pressed/released edges,
   composites, deadzones), InputLog round-trip + corrupted-file rejection, headless Application stepping.
   Window tests go in test suite `"window"` and skip gracefully when GLFW cannot initialize (no display);
   `scripts/test.py` runs them under `xvfb-run` on Linux when available.
