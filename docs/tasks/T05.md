# T05 — Serialization, projects, assets, data tables

Read first: `AGENTS.md`, D-014, D-022, D-025..D-027 in `docs/DECISIONS.md`. Builds on T01–T04.

## Deliverables (with doctest tests)
1. **JSON field serialization** (`Serialization/`): generic `FieldValue` ↔ JSON for every `FieldType`
   (vectors as arrays, quats as `[x,y,z,w]`, UUIDs/handles as `"0x..."` strings, enums by name, colors as
   arrays). Unknown fields → warning, missing fields → default. Never throw past the boundary (catch
   nlohmann exceptions → `Result` errors with JSON pointer paths).
2. **SceneSerializer**: `.gscene` = `{ "Version", "Name", "Seed", "Settings": {...}, "Entities": [ { "UUID",
   "Components": { "<Name>": { fields } } } ] }`. Stable output: entities in hierarchy pre-order (roots by
   child order), components in registry name order, fields in registration order; 2-space indent, trailing
   newline. Load creates entities with stored UUIDs, then wires hierarchy. Round-trip test: save → load → save
   is byte-identical and state hash equal. Version field + migration hook table.
3. **Prefabs**: `.gprefab` (same entity format, single root). `PrefabInstanceComponent` (prefab handle +
   source entity UUID). `PrefabUtils::CreateFromEntity`, `Instantiate(world, prefab, parent, transform)` —
   remaps UUIDs (deterministic via world RNG at runtime; `UUID::Generate` in editor), remaps internal
   Entity-typed field references to the new UUIDs.
4. **Project** (`Project/Project.h`): `.gproject` JSON — Name, Version, StartScene, directories (Assets,
   Scripts, Data, Scenes, Comments), SimulationHz, DefaultSeed, InputActions path, Rendering defaults
   (environment HDRI handle, tonemapper, exposure), export settings. `Project::New(dir, name)` scaffolds folders
   + default files; `Project::Load(path)` mounts the project directory in the VFS; active project singleton +
   explicit instances for tools.
5. **AssetManager** (`Asset/`): `AssetHandle` (UUID), `AssetType` enum (Scene, Prefab, Texture, Mesh, Material,
   Environment, Script, Audio, Font, VectorGraphic, DataTable, AnimationClip, Skeleton, InputActions — extend
   later), `.meta` sidecar JSON (`Handle`, `Type`, `ImportSettings`) created on import/scan;
   `AssetRegistry` (handle ↔ path ↔ type, built by scanning the project via VFS; detects missing/duplicate
   handles and orphaned metas with clear warnings); `Asset` base class; `IAssetImporter`/loader registry by type
   (real importers for textures/meshes arrive in T08 — implement DataTable, Scene, Prefab loaders now);
   `AssetManager::GetAsset<T>(handle)` with caching (`Ref`), `ReloadAsset`, `IsLoaded`, dependency list;
   synchronous loading for now with an API that allows async later; path ↔ handle helpers for tools.
6. **DataTable** (`Asset/DataTable.h`): RFC-4180 CSV parser/writer (quotes, escaped quotes, embedded newlines,
   UTF-8 BOM, CRLF/LF), header row = column names with optional `:type` suffix (`int`, `float`, `bool`,
   `string`, `asset`, `entity`); untyped columns inferred. First column = unique row id. API: `GetRow(id)`,
   `GetValue(rowId, column)` → `FieldValue`, `SetValue`, `AddRow/RemoveRow`, `Columns`, `Save`.
   `DataRefComponent` (Table AssetHandle + RowId) registered in reflection. Errors: duplicate ids, bad types →
   `Result` errors with line/column.
7. **Tests**: every FieldType JSON round-trip, scene round-trip byte-identical, malformed JSON reporting,
   prefab instantiate with internal reference remap, project scaffold + load, asset scan with metas
   (missing/duplicate/orphan), CSV edge cases (quotes, newlines, BOM, CRLF), typed columns, DataTable write
   round-trip. Use a temp directory fixture helper (`GambitTests/src/TestUtils/TempDirectory.h`).
