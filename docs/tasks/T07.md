# T07 — Graphics device (NVRHI/Vulkan), shader pipeline, readback, golden tests

Read first: `AGENTS.md`, D-005, D-030, D-031, D-032 in `docs/DECISIONS.md`. Builds on T01–T03.
Reference for NVRHI device bring-up: NVIDIA Donut's `DeviceManager_VK.cpp` (MIT) — adapt, don't copy blindly.

## Deliverables (with tests)
1. **Build**: wire NVRHI (Vulkan backend only, validation layer target, no D3D) and glslang (build only the
   standalone compiler, `ENABLE_OPT=OFF`, no tests) in `ThirdParty/CMakeLists.txt`. CMake function
   `gb_add_shaders(<target> <sources...>)` compiles `Gambit/Shaders/**/*.{vert,frag,comp,geom}.glsl` with the built
   glslang (`--target-env vulkan1.2`, `-g` in Debug, include dir `Gambit/Shaders/Include`, depfiles so header
   edits rebuild), then embeds all SPIR-V into a generated `.cpp` (CMake script, no Python dependency at build
   time) exposing `ShaderLibrary::Find("PBR.frag")` → `std::span<const uint32_t>`. Shader compile errors must
   fail the build with the glslang message.
2. **`RHI/GraphicsDevice`** (`Gambit/src/Gambit/RHI/`): `GraphicsDeviceSpecification` (app name, validation
   on/off, vsync, preferred GPU index/name, headless, back-buffer format/size for headless, frames in flight).
   - Instance via dynamic loader (`vk::DynamicLoader` + `VULKAN_HPP_DEFAULT_DISPATCH_LOADER_DYNAMIC_STORAGE` in
     exactly one TU), portability enumeration when available (MoltenVK), debug-utils messenger → core logger
     (errors as `GB_CORE_ERROR`, and a counter tests can assert is 0).
   - Physical device selection (discrete > integrated > cpu; required: Vulkan 1.2+, timeline semaphores,
     synchronization2 and whatever NVRHI requires; clear error listing missing features otherwise).
   - Logical device + queues, `nvrhi::vulkan::createDevice`, wrapped by `nvrhi::validation` when validation on.
   - Windowed: GLFW surface, swapchain create/recreate on resize/out-of-date, sRGB/UNORM format choice,
     present mode from vsync, per-frame semaphores/fences, `BeginFrame()`/`GetCurrentBackBuffer()`/`Present()`.
   - Headless: offscreen back buffer textures, same frame API so renderers don't care.
   - `WaitIdle`, `GetNvrhiDevice()`, device info (name, driver, limits) for logs/editor.
3. **Readback & images** (`RHI/Image.h` or `Renderer/Image.h`): CPU `Image` (width, height, format RGBA8 /
   RGBA16F / RGBA32F, pixels), `GraphicsDevice::ReadbackTexture(texture, mip, slice)` → `Result<Image>`,
   PNG save/load (stb_image_write/stb_image; the single `STB_IMAGE_IMPLEMENTATION` TU lives in the engine),
   conversion helpers, `ImageCompare(a, b, perChannelTolerance, maxBadPixelFraction)` → stats + diff image.
4. **Shader & pipeline helpers**: `ShaderCache` (name + stage → `nvrhi::ShaderHandle`, cached), small helpers for
   common binding-layout/pipeline creation, a fullscreen-triangle vertex shader shared by post passes.
5. **Golden-image test harness** (`GambitTests/src/TestUtils/Golden.h`): render → readback → compare with
   `GambitTests/Golden/<Name>.png`; on mismatch write actual + diff to `build/test-output/`; when
   `GB_UPDATE_GOLDEN=1` write the golden instead. GPU tests skip (with a message) when `GB_TEST_NO_GPU=1` or no
   Vulkan device exists. A shared headless `GraphicsDevice` fixture so GPU tests don't recreate devices.
6. **Tests** (suite `gpu`): device creation headless (0 validation errors), clear-color readback exact,
   triangle golden image (`Golden/Triangle.png`), compute shader writes buffer → readback values, texture
   upload/readback round-trip for RGBA8 and RGBA16F, resize of headless back buffer. Window+swapchain test in
   suite `window` (Xvfb + lavapipe on Linux): create window, render 3 frames, resize, render, destroy.
7. **Runtime**: `GambitRuntime` opens a window and clears/presents each frame using the device (headless
   `--frames N` path renders offscreen). Validation errors must be zero in all tests.
