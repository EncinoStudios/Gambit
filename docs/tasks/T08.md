# T08 — Renderer core: textures, meshes, materials, glTF, forward PBR

Read first: `AGENTS.md`, D-022, D-025, D-030..D-032, D-080 in `docs/DECISIONS.md`, `docs/guides/Rendering.md`.
Builds on T04, T05, T07.

## Architecture (normative)
- **Extraction**: `RenderExtractionSystem` (PreRender phase, runs in edit mode) copies ECS data into a
  `RenderScene` (cameras, lights, draw items with current + previous world matrices, environment, debug draw
  list). `SceneRenderer::Render(const RenderScene&, const RenderView&, float alpha, target)` never touches the
  World. Interpolation between previous/current tick transforms uses `alpha` (decouples render rate from sim).
- **SceneRenderer** owns pass objects (`DepthPrepass`, `ForwardPass`, later shadows/SSAO/post) with explicit
  inputs/outputs; render targets sized per view; HDR scene color `RGBA16F`; a temporary simple tonemap+sRGB
  output pass (T09 replaces it with the full post chain). Multiple views (editor viewport + game camera) supported.
- **GPU data**: per-frame constant buffer (view/proj, camera pos, time, exposure), per-draw push constants
  (model, normal matrix index or packed), material constant buffers + binding sets cached per material
  version, lights in a structured buffer (up to `MaxLights = 256`, simple forward loop).

## Deliverables (with tests)
1. **Texture assets**: importer for png/jpg/tga/bmp/hdr (stb_image), import settings (sRGB/linear, generate
   mips, filter, wrap), mip generation (compute shader or blit chain), `Texture2D` asset, default textures
   (white, black, flat normal, checker).
2. **Mesh assets**: `MeshSource` (CPU: positions, normals, tangents, uv0, uv1, colors, joints, weights,
   indices, submeshes with material slot, AABB/bounding sphere) + GPU `Mesh`. glTF 2.0 importer (cgltf, `.gltf`
   and `.glb`, embedded and external buffers/images, all primitive modes reduced to triangles, missing
   normals → generated, missing tangents → MikkTSpace (add `ThirdParty/mikktspace`, zlib, per D-003 rules),
   KHR_texture_transform, KHR_materials_emissive_strength, KHR_mesh_quantization tolerated). A glTF file is a
   **Model** asset whose sub-assets (meshes, materials, textures, later skins/clips) get stable handles recorded
   in the `.meta` (`SubAssets`), so re-import keeps references. `MeshFactory` built-in meshes (Cube, Sphere,
   Plane, Capsule, Cylinder, Cone, Torus, Quad) with fixed well-known handles.
3. **Material** (`.gmat`, reflection-described so the inspector/serializer work generically): BaseColor
   factor+texture, Metallic, Roughness, MetallicRoughness texture, Normal texture+scale, Occlusion
   texture+strength, Emissive color+texture+strength, AlphaMode Opaque/Mask/Blend, AlphaCutoff, DoubleSided,
   UV tiling/offset. glTF materials import into material sub-assets.
4. **Components** (reflected): `MeshRendererComponent` (Mesh/Model handle, SubmeshIndex (-1 = all),
   MaterialOverrides array, CastShadows, ReceiveShadows, Visible), `CameraComponent` (Perspective/Orthographic,
   VerticalFOV, Near, Far, OrthoSize, Primary, ClearColor), `DirectionalLightComponent` (Color, Illuminance lux,
   CastShadows), `PointLightComponent` (Color, Intensity lumens, Range), `SpotLightComponent` (+ Inner/Outer
   cone angles). `ModelUtils::Instantiate(world, model)` creates the glTF node hierarchy as entities; command
   `model.instantiate` + `asset.import` support for models in the CommandRegistry.
5. **Shaders**: depth prepass, PBR forward (Cook-Torrance GGX, height-correlated Smith, Schlick Fresnel,
   Lambert diffuse, glTF spec-compliant alpha modes, normal mapping with MikkTSpace convention, physical light
   units with exposure), unlit debug lines (depth-tested and overlay), temp tonemap.
6. **Debug draw**: renders the debug-draw queue from T11 (`Debug.DrawLine/...`) and engine debug shapes.
7. **Tests**: texture import (formats, sRGB flag, mips count), glTF import of generated test files (write a
   small generator `tools/gen_test_gltf.py` or generate in C++ with `cgltf_write`; commit the outputs under
   `GambitTests/Assets/`), sub-asset handle stability across re-import, MikkTSpace tangents on a known mesh,
   MeshFactory geometry invariants (normals unit length, winding, bounds), material serialization round-trip,
   extraction/interpolation unit tests (no GPU), golden images (gpu suite): PBR sphere grid (metal × roughness)
   under one directional + point lights, textured glTF model, alpha mask/blend ordering, debug lines.
   Zero validation errors.
