# T09 — IBL, skybox, HDR post-processing

Read first: `AGENTS.md`, D-032, D-033, D-080 in `docs/DECISIONS.md`, `docs/guides/Rendering.md`. Builds on T08.

## Deliverables (with tests)
1. **Environment asset**: `.hdr` (Radiance RGBE via stb_image float) equirect → GPU cubemap (compute, size from
   import settings, default 512) → diffuse irradiance (SH9 projected on GPU or 32² cube; pick one and document)
   → GGX prefiltered specular cubemap mip chain (importance sampling with mip-filtered samples, ~5–6 roughness
   levels) → shared BRDF integration LUT (RG16F 256², generated once). Processing runs once at load; results
   cached in the asset. `EnvironmentComponent` (Environment handle, Intensity, Rotation (yaw degrees), SkyboxVisible,
   SkyboxLod/blur) — one active per scene (first found, deterministic order); project default environment.
2. **HDRIs**: add 2–3 CC0 Polyhaven 1k HDRIs to `Projects/Shared/Environments/` (or a shared engine content
   folder decided in your report) fetched from the three.js repository mirror
   (`https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/textures/equirectangular/`, e.g.
   `venice_sunset_1k.hdr`, `quarry_01_1k.hdr`, `royal_esplanade_1k.hdr` — confirm each originates from
   Polyhaven and is CC0, and record them in `ATTRIBUTION.md` per D-080). `scripts/fetch_hdri.py <polyhaven_name>
   [--res 1k|2k|4k]` downloads from Polyhaven's public API/CDN for users with access. Procedural fallback sky
   (analytic gradient/Preetham-style) generated as an environment when no HDRI is assigned.
3. **PBR integration**: split-sum specular IBL + diffuse irradiance with specular occlusion hook (SSAO from T10
   multiplies ambient), environment rotation/intensity.
4. **Skybox pass** (depth-equal far plane, rotation, LOD blur).
5. **Post chain** (`PostProcessComponent` on the camera entity or a global volume; reflected): auto/manual
   exposure (EV100 manual + optional histogram auto-exposure with adaptation speed, deterministic-agnostic as it
   is presentation-only), physically-based bloom (downsample/upsample chain à la COD:AW, threshold-free, intensity),
   tonemappers `ACES` (fitted), `AgX`, `KhronosPBRNeutral`, `Reinhard`, `None`; output sRGB encode or
   swapchain sRGB format aware; optional color grading params (contrast, saturation, white balance — simple).
   Replace T08's temporary tonemap.
6. **Tests** (gpu suite): equirect→cube face orientation golden (labelled test HDR generated procedurally),
   irradiance of a constant-color environment equals that color (numeric readback), prefilter mip 0 ≈ source,
   BRDF LUT matches reference values at sample points within tolerance, golden images: sphere grid lit only by
   IBL for one committed HDRI, each tonemapper on an HDR gradient ramp, bloom on a bright emissive sphere,
   skybox rotation. Zero validation errors.

## Acceptance
`python3 scripts/check.py` green (GCC and Clang), zero warnings. Update `docs/guides/Rendering.md`.

## Report (~150 words)
Choices (SH vs cube irradiance, auto-exposure), deviations, decisions needed, test count, environment load time.
