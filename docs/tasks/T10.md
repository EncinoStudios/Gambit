# T10 — Soft shadows and SSAO

Read first: `AGENTS.md`, D-032 in `docs/DECISIONS.md`, `docs/guides/Rendering.md`. Builds on T08–T09.

## Deliverables (with tests)
1. **Directional cascaded shadow maps**: 4 cascades (configurable 1–4), practical split scheme (lambda),
   texel-snapped stable cascades (no shimmering when the camera moves), depth array texture (D32 or D16 by
   quality setting, resolution 1024–4096), per-cascade bias (constant + slope-scaled + normal offset), cascade
   blending band, shadow distance + fade-out. Casters culled per cascade (AABB vs cascade frustum), alpha-mask
   casters supported.
2. **Soft shadows**: PCF with a rotated Poisson/Vogel disk (deterministic per-pixel rotation from interleaved
   gradient noise), and PCSS (blocker search + penumbra estimate from light angular size) selectable per light:
   `ShadowSoftness` / `LightAngularDiameter` fields on `DirectionalLightComponent`; spot light shadows (single
   map, perspective) and point light shadows (cube map or dual-paraboloid; pick cube) with the same filtering,
   budgeted (max shadowed local lights, setting).
3. **SSAO**: GTAO-style horizon-based AO at half or full resolution (setting) from the depth prepass + view
   normals (add normal output to the prepass if missing), temporal-free (deterministic image per frame), radius,
   intensity, falloff, sample counts settings; depth-aware bilateral blur (separable, edge-preserving); applied to
   ambient/IBL diffuse and specular occlusion only (not direct light). `AmbientOcclusionSettings` and shadow
   settings live in a reflected `RenderSettingsComponent` (scene-level) with project defaults.
4. **Debug views**: cascade colouring, shadow map view, AO-only, normals — selectable via render settings (editor
   uses them later).
5. **Tests** (gpu suite): golden images — sphere on plane with directional soft shadow (PCF and PCSS variants),
   cascade debug view at fixed camera, spot and point light shadows, SSAO-only output of a corner/stair test
   scene, SSAO applied scene; unit tests for cascade split math and texel snapping stability (moving camera by
   sub-texel amounts leaves cascade origins snapped), bias parameters. Zero validation errors. Report frame time
   at 1280×720 on lavapipe with everything on.
