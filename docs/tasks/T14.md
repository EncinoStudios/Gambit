# T14 — Skeletal animation: skeletons, clips, layered animator, GPU skinning

Read first: `AGENTS.md`, D-011, D-020, D-022, D-024, D-042 in `docs/DECISIONS.md`. Builds on T08, T11.
Requirement: "Full animation support including layered partial animations and programmatic animations";
"glTF is the contract".

## Deliverables (with tests)
1. **Import** (extend the glTF importer): `Skeleton` sub-asset (joint names, parent indices, inverse bind
   matrices, rest pose), skinned mesh data (joints/weights, up to 4 influences, normalized), `AnimationClip`
   sub-assets (per-joint T/R/S channels and morph weight channels; LINEAR, STEP, CUBICSPLINE sampling; duration;
   node→joint mapping; clips targeting non-skinned nodes animate entity transforms). Stable sub-asset handles.
2. **Runtime pose**: `Pose` (local TRS per joint), sampling (binary search keyframes, quaternion slerp/nlerp with
   hemisphere correction using DMath), blending (lerp/nlerp by weight), additive (relative to a reference pose,
   clip frame 0 by default), masks (`BoneMask` asset/inline: per-joint weights; built from root joint name +
   include/exclude lists), local→model space, skinning matrices.
3. **`AnimatorComponent`** (reflected; layers as an array field of a reflected struct type — extend the
   reflection with nested struct arrays if not present, generically): Skeleton handle; layers {Name, Clip,
   Time, Speed, Weight, BlendMode Override/Additive, Mask, Loop, Playing}; crossfade state {TargetClip,
   Duration, Elapsed} per layer; RootMotion mode (Ignore/ApplyToTransform). `AnimationSystem` (Animation phase,
   deterministic fixed tick; runs in edit mode for preview) samples layers bottom→top and writes a
   `PoseComponent`/`SkinnedPoseComponent` (runtime, hashed: joint local TRS) consumed by IK (T15), the attachment
   system and render extraction. Animation events (named markers on clips via import extras or `.ganim` sidecar)
   are emitted as world events.
4. **Programmatic animation**: systems/Lua can read and override joint local/model transforms after sampling
   (`PoseOverride` step in LateUpdate phase), plus `TweenComponent` (target field path on any reflected
   component, from/to, duration, easing curve set: Linear, Quad, Cubic, Sine, Expo, Back, Elastic, Bounce
   in/out/inout) with a `TweenSystem` — deterministic, DMath only.
5. **Bone attachments**: `BoneAttachmentComponent` (Animator entity, joint name, offset) to attach props to
   joints.
6. **GPU skinning**: joint palette in a structured buffer per skinned draw (uploaded from extracted
   interpolated poses), skinning in the PBR/depth/shadow vertex shaders; bounds from animated pose.
7. **Lua API** (ApiRegistry-documented): `Animation.Play(entity, clip, {Layer, Fade, Loop, Speed})`,
   `CrossFade`, `Stop`, `SetLayerWeight`, `SetSpeed`, `GetTime/SetTime`, `GetJointLocal/SetJointLocal`,
   `GetJointWorld`, `FindJoint`, `Tween(entity, "Transform.Translation", to, duration, easing)`; events
   `world:Events("AnimationEvent")`.
8. **Content**: procedural test rig generator (`tools/gen_test_gltf.py` or C++ test util with `cgltf_write`):
   a simple skinned humanoid-ish chain (≥ 20 joints) with idle/walk/wave clips generated mathematically,
   committed under `GambitTests/Assets/` and reused by demos.
9. **Tests**: sampling (each interpolation mode, looping/clamping, edge keys), blending/additive/masks numeric
   checks, crossfade weights over time, skinning matrices vs CPU reference, events fire exactly once per loop,
   tweens + easing values, determinism (animated scene hashes identical across runs), golden image of a skinned
   mesh at a fixed pose (gpu suite). Lua tests in `Projects/FeatureTest/Tests/Animation.lua`.
