# T15 — IK, morph targets, baked cloth, DCC pipeline contract

Read first: `AGENTS.md`, D-042 in `docs/DECISIONS.md`, `docs/guides/Animation.md`. Builds on T14.
Requirements: "FK and IK support", "Support for baked cloth physics", "Support future pipeline tools for
Houdini, Blender and Maya. glTF is the contract; DCC presets are documentation only".

## Deliverables (with tests)
1. **IK** (runs after animation sampling, before skinning extraction; DMath only):
   - `TwoBoneIKComponent` (Root/Mid/End joint names, Target entity or position, Pole entity/vector, Weight,
     SoftLimit) — analytic solver with pole vector and stretch-free reach clamping.
   - `ChainIKComponent` (FABRIK: joint chain root→tip, Target, Iterations, Tolerance, Weight, optional per-joint
     hinge/cone constraints).
   - `LookAtIKComponent` (Joint, Target, forward/up axes, max angle, weight, chain distribution across N joints).
   - Foot placement helper example in FeatureTest (raycast + two-bone IK) — Lua.
   FK = direct joint overrides (T14 API) — make sure the docs show FK + IK layering order.
2. **Morph targets**: glTF morph target import (position/normal/tangent deltas), weights on
   `MorphWeightsComponent` (array field, animated by clips' weight channels or scripts), GPU blending (compute
   pre-pass writing a deformed vertex buffer, shared with skinning order: morph → skin), sparse targets.
3. **Baked cloth / vertex animation**: (a) glTF morph-target sequences driven by an animation clip (Blender
   "shape key per frame" style) — works via 2; (b) `VertexCache` asset: compact per-frame position(+normal)
   streams (`.gvcache`, quantized, LZ4) with `VertexCacheComponent` (cache handle, time, speed, loop) played back
   on the fixed tick, GPU upload of the current/next frame and interpolation in the vertex shader;
   (c) `gambit bake-cloth --mesh <asset> --pins <vertex-group or y-threshold> --frames N --out <asset>` offline
   PBD cloth baker (distance + bending constraints, gravity, wind, sphere/plane colliders from a simple JSON
   setup, deterministic) producing a vertex cache — so cloth works even without a DCC.
4. **Pipeline docs** `docs/pipeline/`: `Blender.md`, `Maya.md`, `Houdini.md` — export presets/settings for
   glTF (units/axes: +Y up, meters, -Z forward handled by glTF), skinning limits (4 influences), animation
   baking, naming conventions for clips/markers/LOD/collision (`_COL` suffix → collider import option), how to
   bake cloth to shape keys/morph targets or Alembic→vertex cache conversion (document `tools/` converter
   contract), validation with `gambit asset import`. `docs/pipeline/README.md` states glTF is the contract.
   Also implement importer options `ImportColliders` (`_COL` meshes → collider components) and
   `ImportLights/Cameras` (KHR_lights_punctual, glTF cameras).
5. **Tests**: two-bone IK reaches reachable targets exactly (within 1e-4) and clamps unreachable ones, pole
   control, FABRIK convergence + constraints, look-at angle limits, weight blending with FK pose; morph target
   CPU reference vs GPU compute readback; vertex cache encode/decode error bounds + playback interpolation;
   cloth baker determinism (bit-identical output across runs) and pinned vertices fixed; KHR_lights_punctual
   import; golden image of a morph-deformed mesh and a cloth-cache frame (gpu suite). Lua tests in FeatureTest.
