# T16 — Audio (miniaudio)

Read first: `AGENTS.md`, D-011, D-020, D-022, D-043 in `docs/DECISIONS.md`. Builds on T05, T11.

## Deliverables (with tests)
1. **Build**: miniaudio implementation TU in the engine (`MA_NO_*` trimming of unused features ok; keep
   decoders for WAV/FLAC/MP3; add Vorbis via `stb_vorbis` integration per miniaudio docs).
2. **AudioEngine** (core service): device init with fallback to the null backend (headless/tests/`--no-audio`),
   master/bus volumes (Master, Music, SFX, Voice, UI — mixer groups), listener, voice limit with priority
   stealing, streaming for long clips (music) vs decoded-in-memory for SFX (import setting), clean shutdown.
3. **Assets**: `AudioClip` importer (wav/ogg/mp3/flac) with import settings (stream, loop points, normalize
   off), reading through the VFS (custom `ma_vfs` so packs/remote content work).
4. **Components** (reflected): `AudioSourceComponent` (Clip, Bus, Volume, Pitch, Loop, PlayOnStart, Spatial,
   MinDistance, MaxDistance, Rolloff model, DopplerFactor, runtime `IsPlaying` NotHashed),
   `AudioListenerComponent` (Primary). `AudioSystem` (LateUpdate phase) starts/stops sounds from component
   state and play requests, updates 3D positions/velocities from world transforms; audio never writes back to
   simulation-hashed state (D-043). Play requests from gameplay are queued as world events/commands so replays
   reproduce them.
5. **Lua API**: `Audio.Play(entity)`, `Audio.Stop(entity)`, `Audio.PlayOneShot(clip, {Position, Volume, Pitch,
   Bus})`, `Audio.SetBusVolume(bus, v)`, `Audio.GetBusVolume`. ApiRegistry-documented.
6. **Tests** (null backend, no hardware needed): clip import for each format (generate tiny test files —
   commit small generated WAV/OGG under `GambitTests/Assets/Audio/`), source lifecycle (play/stop/loop/
   one-shot completion), spatial attenuation math per rolloff model, bus volume application, voice limit
   stealing order deterministic, VFS-backed decoding, determinism unaffected (state hash identical with and
   without audio device). Lua tests in FeatureTest.
