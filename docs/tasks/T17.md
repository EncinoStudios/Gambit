# T17 — Renderer2D, sprites, pixel-perfect camera, SDF text

Read first: `AGENTS.md`, D-032, D-034, D-035 in `docs/DECISIONS.md`, `docs/guides/Rendering.md`. Builds on T08–T09.
Requirement: "Pixel perfect 2D functionality".

## Deliverables (with tests)
1. **Renderer2D** (batched, sorted): quads (color/texture/sub-rect), sprites, circles (thickness/fade), lines,
   rounded rects, triangles/meshes (for vector shapes in T18), text; per-batch textures with a bindless-free
   texture array/atlas strategy (document choice); sort by layer then order-in-layer then submission order
   (stable); world-space (in the 3D scene, depth-tested, after opaque or with own pass) and screen-space overlay
   passes (after tonemapping, sRGB-correct blending).
2. **Sprites**: `SpriteRendererComponent` (Texture, SourceRect or SpriteSheet frame, Color, FlipX/Y, Pivot,
   PixelsPerUnit, SortingLayer, OrderInLayer), `SpriteSheet` asset (grid or JSON frames), `SpriteAnimation` via
   `SpriteAnimatorComponent` (frames list, FPS, loop; deterministic fixed tick). Texture import setting
   `PixelArt` (nearest filtering, no mips, clamp).
3. **Pixel-perfect camera**: `PixelPerfectCameraComponent` (ReferenceResolution, PixelsPerUnit, UpscaleMode
   IntegerScale | IntegerScaleWithCrop | Stretch, SnapToPixel): renders into a low-res target at the reference
   resolution then integer-upscales (letterbox/pillarbox), snaps camera + sprite positions to the pixel grid in
   extraction (presentation only, simulation untouched).
4. **Text**: `Font` asset (TTF/OTF via stb_truetype) → SDF (or MSDF if you add msdfgen per D-003 — decide and
   log) glyph atlas generated at import for ASCII + Latin-1 + configurable ranges; kerning; layout with
   alignment, wrapping, line spacing, UTF-8. `TextRendererComponent` (Text, Font, Size, Color, Alignment,
   MaxWidth, outline width/color) in world space; screen-space text via UI (T18). Bundle a default font (ImGui's
   `misc/fonts/Roboto-Medium.ttf`, Apache-2.0, copied into engine content with attribution per D-080).
5. **Tests**: batching (draw-call counts for N sprites with M textures), sort stability, sprite animation frame
   timing on the fixed tick, pixel-perfect scale/crop math per mode and resolution, text layout metrics
   (wrapping, alignment, kerning on known pairs), golden images (gpu suite): pixel-art scene upscaled ×3 with no
   filtering bleed, sprites + circles + lines, text at several sizes and outline.

## Acceptance
`python3 scripts/check.py` green (GCC and Clang), zero warnings. `docs/guides/2D.md`.
