# T18 — Vector artwork (SVG) and ECS game UI

Read first: `AGENTS.md`, D-020, D-034, D-035 in `docs/DECISIONS.md`, `docs/guides/2D.md`. Builds on T17.
Requirement: "Support vector artwork for 2D and UI". ImGui is editor/debug only — game UI is ECS.

## Deliverables (with tests)
1. **VectorGraphic asset**: SVG import via nanosvg (paths, basic shapes, fills incl. linear/radial gradients,
   strokes with width/joins/caps, opacity, transforms; document unsupported features — text, filters, masks —
   and warn on import). Tessellation: adaptive cubic flattening by screen-space tolerance, fills via earcut.hpp
   (even-odd and non-zero handled; holes from sub-paths), strokes expanded to triangles (miter/round/bevel,
   caps), anti-aliasing via analytic edge fringe or MSAA on the 2D pass (decide and log). Tessellations cached per
   scale bucket (power-of-two levels) so zooming stays crisp. Gradients evaluated in the fragment shader.
2. **Components**: `VectorRendererComponent` (Graphic, Color tint, Size/PixelsPerUnit, sorting like sprites) for
   world 2D/3D-plane use; `UIVectorComponent` for UI.
3. **ECS UI** (D-035): `UICanvasComponent` (ScreenSpaceOverlay | WorldSpace, ReferenceResolution, ScaleMode
   ConstantPixel | ScaleWithScreen (match width/height), SortOrder), `UIRectComponent` (AnchorMin/Max,
   Pivot, OffsetMin/Max — RectTransform semantics), `UIImageComponent` (Texture, Color, nine-slice borders),
   `UITextComponent` (Text, Font, Size, Color, Alignment, Wrap, Overflow), `UIButtonComponent` (Normal/Hover/
   Pressed/Disabled colors, Interactable, runtime state), `UILayoutComponent` (Horizontal/Vertical/Grid,
   spacing, padding, child alignment), `UIProgressBarComponent`, `UIToggleComponent`. `UILayoutSystem` computes
   rects hierarchically (deterministic); `UIInputSystem` hit-tests from the tick's InputFrame (mouse position in
   reference coords, gamepad/keyboard navigation with focus) and emits `UIClick`/`UIHover` events (simulation
   events → deterministic, replayable). Rendering through Renderer2D overlay.
4. **Lua API**: `UI.SetText(entity, text)`, `UI.SetVisible`, `UI.GetRect`, `UI.Focus`, events
   `world:Events("UIClick")`; dialogue-friendly helpers live in Lua (`Gambit/Lua/UI.lua`) not C++.
5. **Content**: a few CC0/self-made SVG icons for tests and demos (author them by hand as SVG text).
6. **Tests**: SVG parse of shapes/gradients/transforms, tessellation (area of filled shapes vs analytic within
   1%, holes, stroke widths), scale-bucket selection, UI rect layout for anchors/pivots/offsets across
   resolutions and scale modes, layout groups, hit-testing + click events from synthetic InputFrames, nine-slice
   geometry, golden images (gpu suite): SVG logo at 3 scales, UI screen with buttons/text/progress bar at two
   resolutions. Lua tests in FeatureTest (UI click via simulated input).
