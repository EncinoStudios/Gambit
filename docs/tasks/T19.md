# T19 — Particle system

Read first: `AGENTS.md`, D-011, D-020, D-024 in `docs/DECISIONS.md`. Builds on T08–T09, T11, T17.
Needed by the poker demo ("different hands create particle effects emanating from the cards") and destruction.

## Deliverables (with tests)
1. **Model**: particles are simulated on the CPU on the fixed tick with the world RNG (deterministic,
   replay-safe; particle state is not ECS entities — it is per-emitter runtime storage owned by the
   `ParticleSystem`, included in the state hash via an emitter-level hash). GPU renders instanced billboards.
2. **`ParticleEmitterComponent`** (reflected, nested structs allowed): Playing, Looping, Duration, Prewarm,
   MaxParticles, SimulationSpace Local/World, EmissionRate, Bursts[] {Time, Count, Cycles, Interval}, Shape
   {Point, Sphere, Hemisphere, Cone, Box, Circle, Edge, MeshSurface (mesh handle)} with radius/angle/size,
   start values as ranges {Lifetime, Speed, Size, Rotation, Color (gradient-sampled)}, modules: Gravity,
   Drag, VelocityOverLifetime, ColorOverLifetime (gradient keys), SizeOverLifetime (curve keys),
   RotationOverLifetime, Noise (deterministic value noise, DMath), Attractor (point/entity), Collision with
   ground plane (bounce/dampen; physics-scene collision optional via raycasts — decide and log), SubEmitters
   on death/birth (limited depth), Trails optional (skip if too large; log it). Rendering: Texture/flipbook,
   BlendMode Additive/Alpha/Premultiplied, Lit/Unlit (unlit + emissive HDR for bloom), SortMode, soft particles
   (depth fade), billboard modes (camera-facing, velocity-stretched, horizontal).
   Curves/gradients are reusable reflected types (`Curve`, `Gradient`) — add them to the reflection
   `FieldType` set generically (serialization + inspector + Lua access).
3. **Particle effect assets**: `.gparticle` (serialized emitter set) so effects are reusable; spawn via prefab or
   `Particles.Spawn(effect, position)`.
4. **Lua API**: `Particles.Play/Stop/Emit(entity, count)/Spawn(effect, pos, rot)/SetRate`.
5. **Tests**: emission counts per rate/bursts over N ticks, lifetime expiry, shapes distribution bounds,
   curves/gradients evaluation, sub-emitters, determinism (hash identical across runs; World::Copy then continue
   identical), local vs world space under moving emitter, golden image (gpu suite) of a fixed-seed burst at a
   fixed tick with additive HDR particles + bloom. Lua tests in FeatureTest.
