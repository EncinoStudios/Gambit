# T20 — Editor shell: ImGui on NVRHI, viewport, hierarchy, inspector, gizmos, play mode

Read first: `AGENTS.md`, D-022, D-050, D-051 in `docs/DECISIONS.md`, `docs/guides/Automation.md`,
`docs/guides/Rendering.md`. Builds on T06–T10 (and whatever later modules exist).
Rule: every mutating action goes through a `CommandRegistry` command (undoable); panels never mutate the World
directly.

## Deliverables (with tests)
1. **ImGui integration** (engine `ImGui/` module, compiled out in `Dist`): NVRHI renderer backend written for
   ImGui 1.92+ (dynamic font atlas / `ImGuiBackendFlags_RendererHasTextures` texture create/update/destroy,
   `RendererHasVtxOffset`), GLFW platform backend from imgui, docking + multi-viewport (multi-viewport optional
   on Linux/Wayland — gate by config), DPI scaling via content scale, fonts (Roboto from engine content +
   ImGui default mono), dark theme in Gambit style. `ImGuiLayer` integrated with `Application` layers.
2. **Editor app** (`GambitEditor`): `EditorLayer` with dockspace + menu bar (File: New/Open Project, New/Open/
   Save Scene, Save All; Edit: Undo/Redo, Duplicate, Delete; View: panels; Play: Play/Pause/Step/Stop),
   recent projects, project selection on startup, window title with dirty marker, keyboard shortcuts (Ctrl+S,
   Ctrl+Z/Y, Ctrl+D, Delete, F focus, W/E/R gizmo modes, Q none, Ctrl+P play). Settings persisted per user
   (`imgui.ini` + `EditorSettings.json` in a user config dir, never in the project).
3. **Viewport panel**: renders the active scene via `SceneRenderer` into an offscreen target shown as an ImGui
   image; editor camera (fly WASD+RMB, orbit Alt+LMB, pan MMB, zoom wheel, focus selection) — editor camera is
   not an entity; picking (entity-ID buffer or ray vs bounds — choose GPU ID buffer for exactness), selection
   outline, grid, light/camera icons (vector icons from T18 if available, else simple debug-draw shapes),
   gizmos via ImGuizmo (translate/rotate/scale, local/world, snapping with configurable steps, multi-select
   pivot) → `component.set` commands merged into one undo step per drag; render-settings debug view selector;
   stats overlay (frame time, draw calls).
4. **Scene hierarchy panel**: tree with drag-drop reparent/reorder, multi-select (Ctrl/Shift), rename inline,
   context menu (create empty/primitive/light/camera, duplicate, delete, create prefab), search filter.
5. **Inspector panel**: fully reflection-driven widgets for every `FieldType` (incl. arrays, nested structs,
   curves/gradients when present, enums, asset pickers with drag-drop from content browser, entity pickers),
   attribute-aware (ranges, tooltips, read-only, hidden, categories), multi-entity editing of common
   components, add/remove component menu (C++ + script components), comment badge placeholder for T21.
6. **Play mode**: Play copies the edit World (`World::Copy`), runs simulation with live input; Pause/Step
   (single fixed tick); Stop restores the edit World; play state exposed via `play.start/pause/step/stop`
   commands (so automation can drive it); viewport tint during play; input recording on by default during play
   (InputLog kept for replay in T21).
7. **Headless testability**: editor logic split so panels' command usage and play-mode state machine are unit
   testable without a window; ImGui backend tested by rendering an ImGui frame headless and golden-comparing
   (gpu suite). `GambitEditor --headless --project P --script <commands.jsonl>` runs commands and exits (used by
   tests).
8. **Tests**: play/stop restores exact state hash, step advances one tick, gizmo drag merges into one undo,
   picking returns the right entity in a test scene (gpu), inspector edit → command → undo, hierarchy reparent
   via command, ImGui golden frame.
