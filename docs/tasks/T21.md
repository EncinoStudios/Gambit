# T21 — Editor panels: content, console, spreadsheets, comments, replay

Read first: `AGENTS.md`, D-027, D-050..D-052, D-012 in `docs/DECISIONS.md`, `docs/guides/Editor.md`. Builds on T20.

## Deliverables (with tests)
1. **Content browser**: project asset tree + grid/list, thumbnails (textures; meshes/materials rendered
   offscreen and cached in `<Project>/.gambit/Thumbnails` (gitignored)), import via drag-drop of OS files
   (`asset.import`), create (scene, material, prefab, script from template, data table, particle effect),
   rename/move/delete through commands that keep `.meta` handles stable, drag assets into viewport/inspector.
   File watching: external changes (agents editing files!) trigger reimport/reload (polling watcher, debounced).
2. **Console panel**: log ring buffer with level filters, search, collapse duplicates, click-to-copy, and a
   command line that executes registry commands (`entity.create --name Foo`) — same parser as the CLI.
3. **Data table editor**: spreadsheet grid for `DataTable` assets (sortable columns, inline typed editing,
   add/remove rows/columns, multi-cell paste from clipboard TSV/CSV, find/replace in column) through `data.*`
   commands; save back to CSV.
4. **Bulk component editor**: pick a component type → table of every entity in the scene having it (rows) ×
   fields (columns), inline edit, multi-row set ("fill down", set column to value, numeric scale by %), filter
   by name/tag/field expression, export/import CSV — via `bulk.*` commands (one undo group per operation).
5. **Comments panel** (D-052): list/filter (open/resolved, author, target kind), thread view with replies,
   resolve/reopen, create comment on selected entity/component/asset/position; viewport pins for entity/position
   comments (click to open thread); inspector badge on entities/components with open comments; content browser
   badge on assets with comments. All through `comment.*` commands. Comments created by agents appear live
   (file watcher).
6. **Replay panel**: list recorded `InputLog`s from play sessions (stored in `<Project>/.gambit/Replays`),
   replay with timeline scrub (re-simulate from start to tick — deterministic), per-tick state hash display,
   "verify determinism" button (re-run and compare hashes), export log for bug reports. Commands
   `replay.list/play/verify`.
7. **Project settings + render settings windows** (reflection-driven): physics layers matrix, input actions
   editor, simulation Hz, default environment, export settings.
8. **Tests**: file watcher reimport, console command parsing parity with CLI, data table edit commands +
   undo, bulk ops (fill down, scale) + undo, comment pins anchor resolution, replay verify passes for a
   FeatureTest scene and detects injected divergence; headless where possible.
