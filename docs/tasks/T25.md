# T25 — FeatureTest project: every component and the entire scripting API

Read first: `AGENTS.md`, D-005, D-041 in `docs/DECISIONS.md`, `docs/guides/Scripting.md`, `docs/api/Lua.md`.
Builds on everything before it. Requirement: "Setup a scene used for testing, which tests every single feature in
the engine — all components, and entire scripting API".

## Deliverables
1. **Coverage tooling** (engine + CLI): `gambit coverage --project P [--json]` reports (a) every registered
   component type (C++ and engine Lua) and whether it appears in at least one FeatureTest scene and is exercised by
   at least one test, (b) every ApiRegistry entry and whether a test called it (runtime call counting in the
   Lua binding layer when a coverage flag is set), (c) every registry command and whether a test executed it.
   Exit non-zero when anything is uncovered. Wired into CTest so CI fails on uncovered features.
2. **`Projects/FeatureTest/`** completed:
   - `Scenes/FeatureShowcase.gscene` — one scene that visibly contains every component type (meshes, materials,
     all lights, environment, post settings, physics bodies of every collider type + joints + character,
     animated skinned character with layers/IK/morphs/cloth cache, audio sources, sprites, pixel-perfect camera
     sub-scene or separate scene, vector art, UI canvas with every widget, particles, data refs, prefab instances,
     tweens, script components). Must look good in screenshots (it doubles as the engine showcase).
   - `Tests/*.lua` — tests per module covering every ApiRegistry entry and every component (spawn, mutate,
     simulate, assert), including error cases (bad args produce clear Lua errors).
   - `Tests/Commands.lua` or C++ integration tests covering every registry command.
   - Golden screenshots of the showcase scene from 3 cameras (gpu suite via `render.screenshot`).
3. **CI**: coverage + FeatureTest tests + determinism verification run on Linux; macOS/Windows run non-GPU parts.
4. Fill any gaps found in earlier modules (bugs found while writing tests get regression tests).

## Acceptance
`gambit coverage` reports 100% for components, API entries and commands; `python3 scripts/check.py` green.

## Report (~150 words)
Coverage numbers, bugs found/fixed, deviations, decisions needed.
