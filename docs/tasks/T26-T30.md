# T26–T30 — Demo projects

Read first: `AGENTS.md`, `docs/guides/*` (Scripting, Physics, Animation, 2D, Particles, Editor, Automation),
`.claude/skills/build-game-with-gambit/SKILL.md`. Demos are **content only** (scenes, Lua, data, assets) in
`Projects/<Name>/` — if a demo needs an engine feature that is missing, implement it properly in the engine with
tests (and note it in the report), never hack around it in Lua. Each demo:
- builds its content through the `gambit` CLI/MCP commands or editor where practical (authoring files by hand is
  allowed for Lua and CSV), uses CC0/self-made assets only (D-080), procedural meshes where possible;
- has Lua tests (`Tests/`) that play the demo with simulated input (golden-path playthrough + key mechanics) and
  a determinism check, run in CI;
- has a `README.md` (controls, what features it showcases) and 2–3 screenshots in `Projects/<Name>/Screenshots/`
  rendered with `render.screenshot`;
- exports successfully with `gambit export` and runs headless in the exported runtime.

## T26 — Walking sim ("Lantern Walk", ~2 minutes)
First-person walk through a small evening landscape (terrain mesh from a heightfield generator, props from
MeshFactory, HDRI sky with soft shadows + SSAO) to a lighthouse. 3–4 NPC/encounter points with **branching
dialogue** stored in `Data/Dialogue.csv` (columns: Id, Speaker, Text, Choice1Text, Choice1Next, Choice2Text,
Choice2Next, Condition, SetFlag) — swapping all dialogue = editing one CSV. Flags stored in a `StoryState`
component; at least two endings depending on choices. Dialogue UI via ECS UI + vector art speech panel; footstep
audio; ambient music bus. Tests: playthrough of each branch reaching each ending.

## T27 — Parkour sandbox
Character controller with run, sprint, jump, coyote time, jump buffering, wall-run, wall-jump, vault/mantle
(shape casts), slide; first/third-person toggle (V) with spring-arm camera collision; course of platforms,
moving kinematic platforms, timer + checkpoints + best time in UI; animated character (procedural rig from T14)
with layered upper-body animation + foot IK. Tuning values in `Data/Movement.csv`. Tests: scripted input runs
the course start→finish under a time bound; each move triggers in a test.

## T28 — Texas Hold'em tabletop
Tabletop-simulator style: physics table, 52 physics cards (thin boxes, vector-art faces from generated SVG suits/
ranks), chip stacks; pick up/drag/flip/throw with the mouse (kinematic grab with spring); a dealer button that
runs a Hold'em hand (shuffle with the world RNG, deal hole + community cards with animated tweens, simple AI
opponents (3) with deterministic betting logic, pot/side-pot accounting, hand evaluator with full ranking).
When a hand is revealed/won, particle effects emanate from the winning cards — a distinct effect per hand rank
(pair, two pair, trips, straight, flush, full house, quads, straight flush, royal flush) defined in
`Data/HandEffects.csv` → `.gparticle` assets. Tests: hand evaluator exhaustive known cases, deterministic deal
for a seed, full hand flow with AI, effect selection per rank.

## T29 — Destruction demo
Walls/towers/pillars that fracture: `FractureComponent` (engine feature: deterministic Voronoi fracture of convex
meshes into N convex chunks at bake time via `gambit fracture` and/or at runtime when health reaches 0;
chunks become dynamic bodies with inherited velocity, chunk glue via breakable fixed joints so structures
collapse progressively), projectile launcher (mouse), explosion impulse with radius falloff, debris particles +
dust, audio, slow-motion toggle (time scale only affects presentation interpolation or the sim rate —
decide deterministically), reset key. Tests: fracture determinism (identical chunks for a seed), volume
conservation of chunks within 1%, collapse sequence state hash stable across runs.

## T30 — Agent-built Tetris (tooling validation)
Built **only through `gambit` CLI/MCP commands** (no hand-written scene files; Lua scripts written via
`script.write`), by an agent that reads only `docs/guides` + the build-game skill, recording the session's
command log in `Projects/Tetris/BUILD_LOG.jsonl` (replayable with `gambit batch`). Pixel-perfect 2D, SRS
rotation with wall kicks, 7-bag randomizer (world RNG), hold, ghost piece, line clears with particles, levels/
speed curve from `Data/Levels.csv`, score UI, game over/restart. Tests: rotation/kick tables, bag fairness,
scripted line clears, determinism. Any tooling gaps discovered are fixed in the engine first (report them).

Engine features added, deviations, decisions needed, test count, screenshot paths.
